## 2) Цель обработки №1: запись и первичный контакт

- Цель: обработка обращений потенциальных и действующих клиентов для записи на
  консультацию/практику, согласования времени, цены, формата и проведения первичной
  консультации.
- Категории персональных данных:
  - ФИО
  - номер телефона
  - Telegram/WhatsApp username
  - сообщения в мессенджерах (включая контактную информацию, пожелания, задачи клиента)
  - технические данные устройства и посещения сайта (IP, тип устройства, браузер)
- Категории субъектов:
  - посетители сайта
  - потенциальные клиенты
  - действующие клиенты
- Правовое основание:
  - согласие субъекта на обработку персональных данных (ст. 6 ч.1 п.1 152-ФЗ),
  - выполнение действий по оформлению и подтверждению консультации/услуги
    (договорно-обязательные отношения между сторонами).
- Перечень действий:
  - сбор, запись, систематизация, накопление, хранение, обновление,
    использование, передача (только по договоренности), блокирование, удаление, уничтожение
- Способы обработки:
  - автоматизированная
  - с передачей по внутренней сети оператора
  - с передачей по сети Интернет (мессенджеры)

## 3) Цель обработки №2: сопровождение и проведение практик

- Цель: ведение переписки до и после сессии/курса, проведение
  консультаций/практик, хранение истории коммуникаций для качества услуги
  и последующего сопровождения.
- Категории персональных данных:
  - вышеуказанные контактные данные
  - запросы по здоровью и сексуальной сфере, если клиент сам их сообщает
  - иные данные, которые клиент добровольно передает для подбора подхода
- Категории субъектов:
  - клиенты
  - участники курсов
  - их законные представители (если есть)
- Правовое основание:
  - согласие субъекта на обработку (ст. 6 ч.1 п.1 152-ФЗ),
  - специальное согласие на обработку данных о здоровье/интимной сфере.
- Перечень действий:
  - сбор, запись, систематизация, накопление, хранение, уточнение,
    использование, передача (предоставление доступа специалисту), блокирование,
    удаление, уничтожение
- Способы обработки:
  - автоматизированная
  - с передачей по внутренней сети
  - с передачей по сети Интернет

- Применение HTTPS на сайте.
- Регламенты по удалению/блокировке доступа и согласованию действий сотрудников.
- Ведение учета действий с персональными данными.
- Меры по обнаружению и реагированию на несанкционированный доступ.
- Политика по хранению и удалению по запросу клиента.
- Проверка и актуализация политик безопасности минимум раз в полгода.

- «Реализация услуги проводится в сфере психологико- телесных практик.
  Клиентские сведения по здоровью обрабатываются только по письменному/текстовому
  подтверждению согласия клиента в переписке».
- «Обработка чувствительных данных не является систематическим сбором медицинской истории,
  используется только для оказания конкретной услуги и сопровождения сеанса/курса».
- «Запрос на удаление или ограничение обработки выполняется по адресу в политике конфиденциальности».
